# Dynamic Multimodal Transport Planning with Drones for Emergency Logistics: Mathematical Model and Heuristic Algorithm - Data and Results

This repository provides the original data, benchmark instances, parameter settings, and experimental results used in the paper:

**Dynamic Multimodal Transport Planning with Drones for Emergency Logistics: Mathematical Model and Heuristic Algorithm**

## Contents
- **/instances/**: Benchmark instances used in the experiments  
- **/parameters/**: Parameter settings for the mathematical model and heuristic algorithm  
- **/results/**: Detailed experimental results (tables, figures, and raw outputs)

## Usage
The data and results are made publicly available to support **transparency and reproducibility**.  
Researchers can directly use these files to replicate or extend our experiments.
